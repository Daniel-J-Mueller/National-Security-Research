# Raws Sources

This category tracks ore and raw-material facility sources, including steel-adjacent industrial sites.

## Priority official sources

1. USGS MRDS / USMIN references
   - Purpose: mine, mill, and mineral-deposit point coordinates for ore production mapping.
   - URL: https://www.usgs.gov/centers/geology-minerals-energy-science-center/science/usmin-mineral-deposit-database
2. USGS Mineral Commodity Summaries
   - Purpose: annual commodity context for iron ore, copper, gold, and other core raw inputs.
   - URL: https://www.usgs.gov/centers/national-minerals-information-center/mineral-commodity-summaries
3. EPA Facility Registry Service
   - Purpose: coordinate-backed steel and heavy-industry facilities using NAICS-based filters after ore sites are normalized.
   - URL: https://www.epa.gov/frs
