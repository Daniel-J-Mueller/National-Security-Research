RadNet CSV File Downloads

Below you will find near-real-time monitoring results for individual RadNet air monitor locations available as downloadable zipped CSV files (Excel). For each location listed you will find the reporting start date for each data stream (gamma gross count rate and exposure rate, if available), as well as links to downloadable ZIP files, organized by year (including current year to date). The zipped CSV files show gamma gross count rates by individual channel range. Learn more about how gamma channel ranges are used by NAREL. To view additional monitoring results, including air filter analysis results, please view the individual RadNet air monitor location webpage.

Near-real-time air data results are displayed in Coordinated Universal Time (UTC). Please use the UTC conversion widget above to convert individual results to your local time zone. Please note that dates in the future will return no data.

NOTE: The RadNet near-real-time data displayed on this website are updated several times daily from a mirrored server to reduce the wait time for display. Learn more about the mirror refresh schedule.
