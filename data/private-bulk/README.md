# Private Bulk Data

This folder keeps one private CSV per category with richer fields than the
public bulk exports when the category supports it.

Current layout:

- `agriculture/agriculture.csv`
- `electrical/electrical.csv`
- `people/people.csv`
- `raws/raws.csv`
- `radiation/radiation.csv`

Metadata summary:

- `bulk_exports_metadata.json`

These are generated by:

- `scripts/build_bulk_exports.py`
