# Private Data Folder

This folder is for sensitive working material that should not be published.

Category layout:

- `electrical/`
- `people/`
- `agriculture/`
- `raws/`
- `radiation/`
- `visualizer/`

Current electrical private reference layout:

- `electrical/eia860_2024/field_directory.csv`
- `electrical/eia860_2024/sensitive_fields_manifest.csv`
- `electrical/eia860_2024/plant_locations_private.csv`
- `electrical/eia860_2024/plant_profiles_private.csv`
- `electrical/eia860_2024/plant_profiles_private_metadata.json`
- `electrical/eia860_2024/plant_coordinates_state_summary_private.csv`
- `electrical/eia860_2024/source_inventory.csv`
- `electrical/visualizer/plants_reference.json`
- `electrical/visualizer/plants_reference_summary.json`
- `visualizer/visualizer_manifest.json`
- `visualizer/datasets/electrical.json`
- `visualizer/datasets/people.json`
- `visualizer/datasets/agriculture.json`
- `visualizer/datasets/raws.json`
- `visualizer/datasets/radiation.json`

These files document the official 2024 EIA-860 layout workbook and identify
location-sensitive fields. The private plant location extract retains exact
coordinate and street address data from the official plant workbook and must
remain outside `/public`.

The `electrical/visualizer/` outputs are generated by:

- `scripts/build_plant_visualizer_assets.py`

They keep the legacy electrical-only asset and also generate the shared
multi-category visualizer manifest under `visualizer/`.

The richer private plant profile is generated by:

- `scripts/build_private_plant_profiles.py`

It keeps exact plant coordinates together with environmental-control fields
from the EIA-860 environmental workbooks and adds join-ready emissions columns.
The current build also populates annual plant-level emissions from official EPA
sources where available:

- `eGRID2023` for CO2, CO2e, CH4, N2O, SO2, NOx, and mercury
- `eGRID PM2.5 2021` for particulate matter

Where EPA coverage is unavailable, some SO2 and particulate fields can still be
filled from EIA-860 design/load-rate values, and other columns remain available
for future private joins.

The `people/` category now also includes:

- `people/municipal_population_town_halls_2024_private.csv`

The `agriculture/` and `raws/` categories hold the richer private category
tables that back the local visualizer and private bulk exports:

- `agriculture/county_food_outputs_2022_private.csv`
- `raws/raw_material_sites_2023_private.csv`
- `radiation/radnet_background_radiation_monitors_private.csv`

The `people/` category can still hold temporary or cloned municipal-reference
inputs used to build public population outputs from Census and town-hall data.

Do not publish exact plant coordinates, exact substation coordinates, or street
address datasets from this folder.
